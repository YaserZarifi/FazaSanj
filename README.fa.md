# فضاسنج

[English](README.md)

فضاسنج برنامه‌ای برای ویندوز ۱۰ و ۱۱ است که نشان می‌دهد فضای دیسک شما کجا رفته، به زبان ساده توضیح می‌دهد هر چیز بزرگ چرا آنجاست، می‌گوید پاک کردن کدام‌ها امن است و اگر پاکشان کنید چه اتفاقی می‌افتد. برنامه فارسی و انگلیسی دارد و بدون راه‌اندازی دوباره بین این دو جابه‌جا می‌شود.

## چه کارهایی می‌کند

- **بررسی سریع** روی درایوهای NTFS جدول فایل‌ها را مستقیم می‌خواند (یک برنامه‌ی کمکی کوچک برای هر بررسی یک بار اجازه‌ی مدیر می‌خواهد). اگر اجازه ندهید، بررسی معمولی همان کار را بدون اجازه‌ی مدیر و کمی کندتر انجام می‌دهد.
- **نمای ساده** ماجرا را در چند جمله می‌گوید: «۴۱۲ گیگابایت از این درایو پر است. بیشترش بازی‌ها، ویندوز و فیلم‌هاست. همین حالا می‌توانید حدود ۱۸ گیگابایت را با خیال راحت آزاد کنید.» یک دکمه هم بعد از دیدن فهرست، بخش امن را آزاد می‌کند.
- **نمای حرفه‌ای** فهرست پوشه‌ها، نقشه‌ی مستطیلی و نمودار حلقه‌ای با امکان رفتن به داخل پوشه‌ها، بزرگ‌ترین فایل‌ها، فضا به تفکیک نوع فایل و پنل جزئیات برای هر مورد دارد.
- **پایگاه دانش** با بیش از ۵۰ قاعده برای ویندوز، مرورگرها، پیام‌رسان‌ها، بازی‌ها، حافظه‌ی موقت کارت گرافیک، ابزارهای برنامه‌نویسی و دیسک‌های مجازی. هر قاعده سطح امنیت دارد (امن، احتمالاً امن، با احتیاط، دست نزنید) و می‌گوید با پاک کردن آن مورد چه می‌شود.
- **یافته‌ها** برای چیزهایی که قاعده‌ها نمی‌شناسند: فایل‌های تکراری، باقی‌مانده‌ی برنامه‌های حذف‌شده، پروژه‌های قدیمی برنامه‌نویسی و فایل‌هایی که مدت‌هاست کسی سراغشان نرفته. این‌ها حدس هستند و هیچ‌وقت «امن» علامت نمی‌خورند.
- **پاک‌سازی با احتیاط**: صفحه‌ی بازبینی، اجرای آزمایشی، سطل بازیافت به‌طور پیش‌فرض، نقطه‌ی بازگردانی اختیاری پیش از کارهای سیستمی، رد شدن از فایل‌های در حال استفاده بدون هیچ زوری، و فهرست مسیرهای ممنوع که هیچ راهی دورش نمی‌زند. همه‌ی کارها ثبت می‌شوند.
- **رشد در طول زمان**: هر بررسی یک عکس کوچک از حجم پوشه‌ها نگه می‌دارد تا ببینید از دفعه‌ی قبل چه چیزی بزرگ شده.
- **هوش مصنوعی اختیاری** (OpenAI، Gemini، Anthropic یا Groq با کلید خودتان) برای پوشه‌هایی که هیچ راه دیگری توضیحشان نمی‌دهد. فقط مشخصات پوشه فرستاده می‌شود، نام کاربری شما همیشه پنهان است، اول دقیقاً می‌بینید چه چیزی فرستاده می‌شود و کلیدها در Credential Manager ویندوز می‌مانند. برنامه بدون این هم کامل کار می‌کند.
- ماندن در سینی ویندوز با هشدار کمبود فضا و بررسی هفتگی، پوسته‌ی روشن و تیره، و به‌روزرسانی خودکار از GitHub Releases.

## نصب

فایل `Fazasanj_x.y.z_x64-setup.exe` را از [آخرین نسخه](https://github.com/YaserZarifi/FazaSanj/releases/latest) دانلود و اجرا کنید. نصب‌کننده هنوز امضای دیجیتال ندارد و ممکن است SmartScreen ویندوز هشدار بدهد. روی «More info» و بعد «Run anyway» بزنید.

## ساختن از روی کد

به ویندوز ۱۰ یا ۱۱، [Rust](https://rustup.rs) (نسخه‌ی stable)، Node.js 22 و pnpm نیاز دارید.

</div>

```
pnpm install
pnpm tauri dev
```

<div dir="rtl">

دستور `pnpm tauri dev` برنامه‌ی کمکی بررسی سریع را هم می‌سازد و سر جایش می‌گذارد. برای ساختن نصب‌کننده `pnpm tauri build --bundles nsis` را اجرا کنید.

### امتحان پاک‌سازی بدون خطر

نسخه‌های توسعه بیرون از یک پوشه‌ی آزمایشی چیزی پاک نمی‌کنند. یک درایو یا پوشه‌ی اضافه را با فایل‌های الکی پر کنید و پوشه‌ی آزمایشی را روی آن بگذارید:

</div>

```
cargo run -p junk-gen -- T:\
```

<div dir="rtl">

بعد پوشه‌ی آزمایشی را در تنظیمات، بخش پیشرفته (یا با متغیر محیطی `DEV_SANDBOX`) تعیین کنید.

## ساختار برنامه

Tauri 2 با هسته‌ی Rust و رابط کاربری Svelte 5 و TypeScript. بخش Rust به چند crate کوچک تقسیم شده است (بررسی‌کننده، برنامه‌ی کمکی MFT، قاعده‌ها، حدس‌ها، پاک‌سازی، هوش مصنوعی، ذخیره‌سازی و لایه‌ای که همه را به هم وصل می‌کند). جزئیات در [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) و برنامه‌ی کار در [docs/PHASES.md](docs/PHASES.md) است.

## توضیح اشتباهی دیدید؟

در صفحه‌ی «درباره» روی «گزارش توضیح اشتباه» بزنید یا [یک issue باز کنید](https://github.com/YaserZarifi/FazaSanj/issues/new). قاعده‌ها در `crates/rules/rules/*.json` هستند و برای افزودن قاعده‌ی تازه لازم نیست کدی تغییر کند.
